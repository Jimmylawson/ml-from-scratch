## 1. Discriminative vs Generative Learning

### Question

What is the difference between a discriminative learning algorithm and a generative learning algorithm?

### Answer

A **discriminative model** learns the decision rule directly.

It models:

$$
p(y \mid x)
$$

or directly learns a map:

$$
x \rightarrow y
$$

Examples:

```text
logistic regression
softmax regression
SVM
```

A **generative model** models how the data is generated by each class.

It models the class-conditional likelihood:

$$
p(x \mid y)
$$

and the class prior:

$$
p(y)
$$

Then it uses Bayes rule:

$$
p(y \mid x) = \frac{p(x \mid y)p(y)}{p(x)}
$$

For prediction, we choose the class with the largest posterior probability:

$$
\arg\max_y p(y \mid x)
$$

Since \(p(x)\) is the same for every class, prediction becomes:

$$
\arg\max_y p(x \mid y)p(y)
$$

Examples:

```text
Naive Bayes
Gaussian Discriminant Analysis
```

### Memory

```text
Discriminative: directly learns p(y | x)
Generative: learns p(x | y) and p(y), then uses Bayes rule
```

## 2. Why Can We Ignore p(x) During Prediction?

### Question

Bayes rule is:

$$
p(y \mid x) = \frac{p(x \mid y)p(y)}{p(x)}
$$

Why can we ignore \(p(x)\) when choosing the predicted class?

### Answer

For prediction, we want:

$$
\arg\max_y p(y \mid x)
$$

Using Bayes rule:

$$
\arg\max_y \frac{p(x \mid y)p(y)}{p(x)}
$$

But \(p(x)\) does not depend on \(y\). It is the same denominator for every class.

So:

$$
\arg\max_y \frac{p(x \mid y)p(y)}{p(x)}
=
\arg\max_y p(x \mid y)p(y)
$$

### Simple Example

Suppose:

```text
class spam numerator = 0.08
class ham numerator  = 0.02
p(x) = 0.10
```

With denominator:

```text
spam = 0.08 / 0.10 = 0.80
ham  = 0.02 / 0.10 = 0.20
```

Without denominator:

```text
spam = 0.08
ham  = 0.02
```

Spam is still larger either way. So for classification, \(p(x)\) can be ignored.

## 3. What Is the Naive Bayes Assumption?

### Question

In Naive Bayes, what is the "naive" assumption?

### Answer

Naive Bayes assumes features are **conditionally independent given the class label**.

$$
p(x_1, x_2, \dots, x_n \mid y)
=
\prod_{j=1}^{n} p(x_j \mid y)
$$

### Important Wording

Naive Bayes does **not** say features are always independent.

It says:

```text
features are independent once we know the class y
```

### Spam Example

For spam classification, words like:

```text
free
prize
winner
```

may be correlated in real life.

But given that a message is spam, Naive Bayes treats each word feature independently:

$$
p(\text{free}, \text{prize}, \text{winner} \mid \text{spam})
=
p(\text{free} \mid \text{spam})
p(\text{prize} \mid \text{spam})
p(\text{winner} \mid \text{spam})
$$

This assumption is not perfectly true, but it makes the model simple and often effective.

## 4. Bernoulli Naive Bayes Feature Parameter

### Question

For Bernoulli Naive Bayes, what does this parameter mean?

$$
\phi_{j \mid y=1}
$$

### Answer

It means:

```text
probability that feature j is present, given the message is spam
```

Formula:

$$
\phi_{j \mid y=1} = P(x_j = 1 \mid y = 1)
$$

For the SMS spam classifier:

$$
\phi_{j \mid y=1}
=
\frac{\text{number of spam messages where word } j \text{ appears}}
{\text{number of spam messages}}
$$

### Example

Let feature \(j\) be the word `free`.

Suppose:

```text
100 spam messages total
"free" appears in 40 spam messages
```

Then:

$$
\phi_{\text{free} \mid y=1} = \frac{40}{100} = 0.40
$$

Meaning:

```text
Given a message is spam, probability that "free" appears is 0.40.
```

For ham:

$$
\phi_{\text{free} \mid y=0} = P(x_{\text{free}} = 1 \mid y = 0)
$$

Suppose:

```text
500 ham messages total
"free" appears in 5 ham messages
```

Then:

$$
\phi_{\text{free} \mid y=0} = \frac{5}{500} = 0.01
$$

Since:

$$
0.40 > 0.01
$$

`free` is spam-indicative.

### Important Correction

\(\phi_{j \mid y=1}\) does not mean every word in the dictionary becomes `1`.

It means the probability that word \(j\) appears given the class is spam.

## 5. Bernoulli Naive Bayes Likelihood

### Question

For binary word features, how do we model \(p(x_j \mid y)\)?

### Answer

In Bernoulli Naive Bayes, each feature is binary:

```text
x_j = 1 if word j appears
x_j = 0 if word j does not appear
```

The Bernoulli probability is:

$$
p(x_j \mid y)
=
\phi_{j \mid y}^{x_j}(1 - \phi_{j \mid y})^{1-x_j}
$$

This formula handles both cases.

### If x_j = 1

$$
p(x_j \mid y) = \phi_{j \mid y}
$$

### If x_j = 0

$$
p(x_j \mid y) = 1 - \phi_{j \mid y}
$$

Using the Naive Bayes conditional independence assumption:

$$
p(x \mid y)
=
\prod_{j=1}^{n}
\phi_{j \mid y}^{x_j}(1 - \phi_{j \mid y})^{1-x_j}
$$

This is the probability of the whole message feature vector under a class.

## 6. Laplace Smoothing

### Question

What is Laplace smoothing, and why do we need it in Naive Bayes?

### Answer

Naive Bayes multiplies many probabilities:

$$
p(x \mid y) = \prod_{j=1}^{n} p(x_j \mid y)
$$

If one word has probability \(0\), then the whole product becomes \(0\).

That is bad because one unseen word can destroy the entire class probability.

Laplace smoothing prevents zero probabilities by adding a small count.

For Bernoulli Naive Bayes:

$$
\phi_{j \mid y}
=
\frac{\text{count}(x_j = 1, y) + \alpha}
{\text{count}(y) + 2\alpha}
$$

If \(\alpha=1\):

$$
\phi_{j \mid y}
=
\frac{\text{count}(x_j = 1, y) + 1}
{\text{count}(y) + 2}
$$

### Why +2 in the Denominator?

Because Bernoulli features have two possible outcomes:

```text
x_j = 1
x_j = 0
```

So smoothing adds probability mass to both outcomes.

### Example

Suppose:

```text
word "prize" appears in 0 ham messages
there are 500 ham messages
```

Without smoothing:

$$
\phi_{\text{prize} \mid \text{ham}} = \frac{0}{500} = 0
$$

With Laplace smoothing:

$$
\phi_{\text{prize} \mid \text{ham}}
=
\frac{0+1}{500+2}
=
\frac{1}{502}
$$

Now the probability is small, but not zero.

## 7. Why Use Logs in Naive Bayes?

### Question

Why do we usually compute Naive Bayes prediction in log space instead of multiplying raw probabilities?

### Answer

Naive Bayes multiplies many small probabilities:

$$
p(x \mid y) = \prod_{j=1}^{n} p(x_j \mid y)
$$

When probabilities are very small, multiplying many of them can underflow to `0` in the computer.

So we use logs.

Products become sums:

$$
\log p(x \mid y)
=
\sum_{j=1}^{n}\log p(x_j \mid y)
$$

Prediction score becomes:

$$
\text{score}(y)
=
\log p(y) + \log p(x \mid y)
$$

For Bernoulli Naive Bayes:

$$
\log p(x \mid y)
=
\sum_{j=1}^{n}
\left[
 x_j \log \phi_{j \mid y}
 + (1-x_j)\log(1-\phi_{j \mid y})
\right]
$$

So:

$$
\text{score}(y)
=
\log p(y)
+
\sum_{j=1}^{n}
\left[
 x_j \log \phi_{j \mid y}
 + (1-x_j)\log(1-\phi_{j \mid y})
\right]
$$

### Why Logs Help

Logs help because:

- products become sums
- sums are easier to compute
- numerical underflow is avoided
- the class with the largest probability also has the largest log probability

## 8. Naive Bayes Prediction Rule

### Question

How does Naive Bayes predict whether a message is spam or ham?

### Answer

For each class, compute a score.

Spam score:

$$
\text{score}(\text{spam})
=
\log p(y=1) + \log p(x \mid y=1)
$$

Ham score:

$$
\text{score}(\text{ham})
=
\log p(y=0) + \log p(x \mid y=0)
$$

Then:

```python
if score_spam > score_ham:
    predict spam
else:
    predict ham
```

In math:

$$
\hat{y}
=
\arg\max_y \left[\log p(y) + \log p(x \mid y)\right]
$$

This is the log-space version of:

$$
\arg\max_y p(x \mid y)p(y)
$$

## 9. Indicative Word Score

### Question

What does this score mean?

$$
\log\frac{\phi_{j \mid 1}}{\phi_{j \mid 0}}
$$

### Answer

This compares how likely a word is in spam versus ham.

$$
\phi_{j \mid 1} = P(\text{word } j \text{ appears} \mid \text{spam})
$$

$$
\phi_{j \mid 0} = P(\text{word } j \text{ appears} \mid \text{ham})
$$

So:

$$
\frac{\phi_{j \mid 1}}{\phi_{j \mid 0}}
$$

means:

```text
how many times more likely the word is in spam than ham
```

Taking log gives:

$$
\log\frac{\phi_{j \mid 1}}{\phi_{j \mid 0}}
$$

### Interpretation

If:

$$
\log\frac{\phi_{j \mid 1}}{\phi_{j \mid 0}} > 0
$$

then the word appears more in spam than ham.

If:

$$
\log\frac{\phi_{j \mid 1}}{\phi_{j \mid 0}} < 0
$$

then the word appears more in ham than spam.

If:

$$
\log\frac{\phi_{j \mid 1}}{\phi_{j \mid 0}} = 0
$$

then the word appears equally often in both classes.

### Example

If `prize` is 4 times more likely in spam than ham:

$$
\text{ratio}=4,
\qquad
\text{score}=\log(4)>0
$$

So `prize` is spam-indicative.

If `later` is 4 times more likely in ham than spam:

$$
\text{ratio}=\frac{1}{4},
\qquad
\text{score}=\log\left(\frac{1}{4}\right)<0
$$

So `later` is ham-indicative.

## 10. GDA Assumption

### Question

What does Gaussian Discriminant Analysis assume about \(p(x \mid y)\)?

### Answer

GDA assumes that the features \(x\), given the class label \(y\), follow a Gaussian distribution.

For binary GDA:

$$
p(x \mid y=0) = \mathcal{N}(\mu_0, \Sigma)
$$

$$
p(x \mid y=1) = \mathcal{N}(\mu_1, \Sigma)
$$

Meaning:

```text
class 0 examples form one Gaussian cloud
class 1 examples form another Gaussian cloud
```

Each class has its own mean:

$$
\mu_0 = \text{center of class 0 cloud}
$$

$$
\mu_1 = \text{center of class 1 cloud}
$$

But both classes share the same covariance matrix:

$$
\Sigma = \text{shared shape/spread of the clouds}
$$

### Prediction Intuition

For a new example \(x\), GDA asks:

```text
Which class Gaussian makes this x more likely?
```

Then it combines the likelihood with the class prior:

$$
\arg\max_y p(x \mid y)p(y)
$$

## 11. Multivariate Gaussian Density

### Question

What is the Gaussian density used in GDA?

### Answer

For a \(d\)-dimensional feature vector:

$$
x \in \mathbb{R}^d
$$

The multivariate Gaussian density is:

$$
p(x; \mu, \Sigma)
=
\frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}
\exp\left(
-\frac{1}{2}(x-\mu)^T\Sigma^{-1}(x-\mu)
\right)
$$

Meaning:

- \(\mu\) is the mean vector.
- \(\Sigma\) is the covariance matrix.
- \(|\Sigma|\) is the determinant of the covariance matrix.
- \(\Sigma^{-1}\) is the inverse covariance matrix.
- \((x-\mu)\) measures how far \(x\) is from the class center.

The term:

$$
(x-\mu)^T\Sigma^{-1}(x-\mu)
$$

is a covariance-aware distance from \(x\) to the mean.

## 12. GDA Parameters

### Question

In binary GDA, what are \(\phi\), \(\mu_0\), \(\mu_1\), and \(\Sigma\)?

### Answer

The assumptions are:

$$
y \sim \text{Bernoulli}(\phi)
$$

$$
x \mid y=0 \sim \mathcal{N}(\mu_0, \Sigma)
$$

$$
x \mid y=1 \sim \mathcal{N}(\mu_1, \Sigma)
$$

Parameters:

$$
\phi = P(y=1)
$$

\(\phi\) is the class prior. It is the Bernoulli parameter for the label \(y\).

$$
\mu_0 = \text{mean vector for class 0}
$$

$$
\mu_1 = \text{mean vector for class 1}
$$

$$
\Sigma = \text{shared covariance matrix}
$$

### Important Correction

\(\phi\) is not "Bernoulli itself."

The label model is Bernoulli:

$$
y \sim \text{Bernoulli}(\phi)
$$

\(\phi\) is the parameter of that Bernoulli distribution.

## 13. GDA Parameter Estimates

### Question

How are GDA parameters estimated from data?

### Answer

Class prior:

$$
\phi = \frac{\sum_{i=1}^{m} 1\{y^{(i)}=1\}}{m}
$$

Mean for class 0:

$$
\mu_0
=
\frac{\sum_{i=1}^{m} 1\{y^{(i)}=0\}x^{(i)}}
{\sum_{i=1}^{m} 1\{y^{(i)}=0\}}
$$

Mean for class 1:

$$
\mu_1
=
\frac{\sum_{i=1}^{m} 1\{y^{(i)}=1\}x^{(i)}}
{\sum_{i=1}^{m} 1\{y^{(i)}=1\}}
$$

Shared covariance:

$$
\Sigma
=
\frac{1}{m}
\sum_{i=1}^{m}
\left(x^{(i)}-\mu_{y^{(i)}}\right)
\left(x^{(i)}-\mu_{y^{(i)}}\right)^T
$$

where:

$$
\mu_{y^{(i)}}
=
\begin{cases}
\mu_0, & y^{(i)}=0 \\
\mu_1, & y^{(i)}=1
\end{cases}
$$

### Intuition

For each example:

1. Pick the mean vector for its class.
2. Compute how far the example is from that class mean.
3. Add the outer product of that difference.
4. Average over all examples.

This gives the shared covariance matrix.

## 14. GDA Prediction Rule

### Question

How does GDA classify a new example?

### Answer

For each class, compute:

$$
\text{score}(y) = \log p(y) + \log p(x \mid y)
$$

For binary GDA:

$$
\text{score}(0)
=
\log(1-\phi) + \log \mathcal{N}(x; \mu_0, \Sigma)
$$

$$
\text{score}(1)
=
\log(\phi) + \log \mathcal{N}(x; \mu_1, \Sigma)
$$

Then:

```python
if score_1 > score_0:
    predict 1
else:
    predict 0
```

In multiclass GDA:

$$
\text{score}(k)
=
\log p(y=k) + \log \mathcal{N}(x; \mu_k, \Sigma)
$$

Then:

$$
\hat{y} = \arg\max_k \text{score}(k)
$$

### Why Logs?

Same reason as Naive Bayes:

- numerical stability
- products become sums
- easier computation

## 15. Naive Bayes vs GDA

### Question

What kind of data is Naive Bayes better suited for, and what kind of data is GDA better suited for?

### Answer

Naive Bayes is often better for:

- text classification
- spam detection
- bag-of-words features
- high-dimensional sparse data
- binary word-present features
- word-count features

Why:

```text
Text data has many features, and most are 0 for each message.
```

Naive Bayes handles this well.

GDA is often better for:

- continuous numeric features
- data that forms Gaussian-like class clusters
- lower-dimensional structured numeric data
- cases where modeling mean and covariance makes sense

Why:

$$
\text{GDA assumes } x \mid y \text{ is Gaussian.}
$$

So it fits data where each class looks like a Gaussian cloud.

Examples:

```text
Naive Bayes: SMS spam classifier
GDA: Iris flower measurements
```
